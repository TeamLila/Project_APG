# How to Play
## Client/APG
1. download the client.zip file from the releases
2. download python (either through the [Microsoft Store](https://apps.microsoft.com/detail/9nq7512cxl7t?hl=de-DE&gl=DE) or through [Python.org](https://www.python.org/downloads/))
3. unzip the client.zip whereever you want it (preferably NOT the downloads folder)
4. run the "main.py" file with python

## Archipelago
### Creating Player YAML
1. download the .apworld From the releases
2. Place the .apworld inside your "Custom worlds" folder
3. create a player YAML through the build-in option creator of archipelago
4. (optional) send your player YAML to the host

### Hosting
1. Place all YAML files inside the "players" folder (including from APG and other games)
2. click "generate" inside the Archipelago launcher
3. Host localy or upload the Generated Zip file at the [Archipelago Website](https://archipelago.gg/uploads)
